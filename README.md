# football_analysis

As computer science student who really loves football, i saw a tutorial on youtube that builds a project like this, with the instruction of the youtube video i built this project.
the project written in python and uses the yolov5 object detection library
the project gets a short video from a football game and analysis the following data:
- each player has a player_id
- the ball game is detected and marked with green arrow
- the player that has the ball is marked with red arrow
- under each player there is cycle in color of the team's shirt
- teams ball possesion (%)
- under each player mention the number of kilometers the player covered and also his run speed
